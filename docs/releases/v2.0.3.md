# pMax Performance Pack v2.0.3

A documentation-only patch release on top of v2.0.2. No runtime, SQL, CI, or
deployment-ladder changes; the deployed image for v2.0.0 remains valid.

## What changed

- README diagrams are re-gridded for readability. The four Excalidraw scenes
  moved from wide five-and-six-column layouts (1932 to 2332 px intrinsic
  width, rendered at roughly 38 percent in GitHub's content column) to
  compact three-and-four-column layouts (952 to 1304 px), so labels render
  about twice as large on the repository page. The `.excalidraw` sources,
  SVG and PNG exports, and QA screenshots are all regenerated from the same
  build pipeline.
- README prose: one contrast sentence stated directly, and the measured
  cost-reference numbers are plain text instead of bold.

## Compatibility

Same requirements as v2.0.0 (Python 3.12, Google Ads API v25 pin).
