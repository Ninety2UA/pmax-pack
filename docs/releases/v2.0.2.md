# pMax Performance Pack v2.0.2

A hardening patch release on top of v2.0.1. No runtime, SQL, or
deployment-ladder behavior changes; the deployed image for v2.0.0 remains
valid. All changes close findings from the 2026-08-31 whole-change-set code
review (five lenses plus an independent cross-model adversarial pass).

## What changed

- Secret scanning: the gitleaks allowlist no longer carries `paths` entries.
  gitleaks ORs allowlist criteria, so a path entry exempted two harness files
  from all scanning; the synthetic fingerprint is now allowlisted by regex
  only, and the harness files scan fully again.
- Workflow tripwire: the no-federation guards (unit test and deploy harness)
  now glob `*.yml` and `*.yaml` including dotfiles, assert the workflow set
  is non-empty, and assert the retired trusted workflow stays absent under
  either extension.
- Deploy harness tree fidelity: private-tree runs now fail (rather than skip)
  when a governed document is missing, via an explicit private-tree
  discriminator; a guard self-test exercises all three tree states with
  mutants. In the private tree the rollback-anchor documents are pinned to
  the exact recorded digest and commit instead of generic phrases.
- Diagram builder (`docs/diagrams/build.py`): the pre-build canvas snapshot
  is durable (kept on disk until an id-verified restore succeeds), a restore
  failure can no longer delete the only snapshot or mask the original build
  error, and the scene/QA invariants gained a 10-test unit suite.
- SQL template render gate: `scripts/parse_sql_templates.py` reports
  exceptions with empty messages instead of crashing, with its own tests.

## Compatibility

Same requirements as v2.0.0 (Python 3.12, Google Ads API v25 pin).
